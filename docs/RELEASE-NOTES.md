- 사망 유닛에 남던 체력바·선택 표시와 별도 풀링 상태 효과를 재생에서 정리합니다. 현재 소유자가 살아 있는 대상이면 효과를 건드리지 않습니다.
- 잔해 메시가 있는 차량의 표시 전용 잔해 생성 경로를 보완합니다. 기존 호출·명시적 소유 잔해를 확인해 중복을 방지하고, 잔해 자신의 물리·화염·소멸 처리는 유지합니다.
- 기종의 양수 사망 연출 유예 시간을 기존 2~30초 제한 없이 존중합니다. 잔해 메시가 없는 드론에 임의의 추락 연출을 넣지 않습니다.
- 실제 경기·자동 녹화 및 기록 형식은 변경하지 않았습니다. 기존 파일을 그대로 사용할 수 있습니다.

동일 파일 4배속 최종 비교에서 초반/중반/후반 평균 FPS는 93.2/69.2/39.9에서 98.0/81.6/41.6으로 측정됐습니다. 단일 PC의 통제되지 않은 병행 부하가 있는 표본이며 성능 보장 수치가 아닙니다. 후반 부하는 남아 있습니다.

실제 전체 재생·종료, 후보의 1·2·4배속/U 반복/카메라 복귀와 142개 자동 테스트를 확인했습니다. 콘도르 잔해 프리팹의 표시 시험은 했지만 실제 사망 시점의 전체 추락·소멸 및 모든 항공기 기종은 미검증입니다. 시험 중 진단 계측 실행 1회에서 크래시가 있었으며 계측을 줄인 완료 재생들에서는 재현되지 않았습니다. 상세 근거와 한계는 docs/DEATH-PRESENTATION-VALIDATION.md에 기록했습니다.
