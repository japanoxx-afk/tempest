v0.3.29

- 리플레이 체력바는 기본 숨김입니다. 왼쪽/오른쪽 Alt를 누르는 동안 표시하고 떼면 숨깁니다. U키로 관전자 HUD를 숨긴 동안에도 숨깁니다. 조작키 설명을 갱신했습니다.
- 기록된 자원 타일 단계와 화면 모델이 어긋나는 문제를 보완했습니다. 재생 중 TempestFieldVolume의 로컬 표시를 동기화하며 실제 자원량·채취·멀티플레이는 변경하지 않습니다. 같은 파일에서 고갈된 타일의 표시 단계가 복원됨을 확인했습니다.
- 체력바가 숨겨진 동안의 좌표 투영/UMG 작업, 새 유닛의 불필요한 전체 후보 비교, 같은 프레임의 중복 객체 이름 조회를 줄였습니다. 이동 보간·애니메이션·정상 효과를 생략하지 않습니다.
- 실제 재생 검증과 성능 측정 범위는 docs/ALT-RESOURCE-VALIDATION.md에 기록했습니다. 모든 장면/배속에서 60FPS를 보장하는 것은 아닙니다.

게임을 종료한 뒤 업데이트하세요. 원본 리플레이 파일은 유지됩니다.
