v0.3.17

- Windows PowerShell 5.1에서 GitHub 체크섬 응답이 바이트 배열로 전달되어 업데이트가 중단되던 오류를 수정했습니다.
- 업데이트 확인·다운로드·검증을 별도 프로세스에서 수행하고 버튼에 진행 상태를 표시합니다. 최신 버전과 실패 원인은 팝업으로 안내합니다.
- 검증을 마친 뒤 런처를 닫아 파일을 교체하고 다시 실행합니다. 설치 실패 시 백업으로 복원하며 오류 로그를 남깁니다.

v0.3.16 이하에서 업데이트 버튼이 실패한다면 이 배포 파일을 직접 압축 해제해 Start.cmd를 실행하세요. 이 PC의 작업 폴더는 수정되어 있으므로 기존 런처를 닫고 다시 실행하면 됩니다.
