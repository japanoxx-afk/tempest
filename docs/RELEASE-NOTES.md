v0.3.20

- 건물·수송체의 수용 목록과 유닛의 컨테이너 정보를 함께 확인합니다. 생산 건물의 대기 유닛과 실제 수용 유닛을 구분합니다.
- 수용 중에는 본체뿐 아니라 선택 원, 조명, 부착 회복 효과와 기타 SceneComponent를 숨기고 외부 선택 충돌을 차단합니다. 하차 시 본체와 브리지가 변경한 표시·충돌을 복원합니다.
- 미니맵 갱신을 실제 시간 기준으로 제한하고 정지한 아이콘의 반복 투영·색상·크기 갱신을 줄였습니다. 월드 이동·애니메이션과 기록 이벤트의 처리는 유지합니다.
- 발사체의 클래스·이동 컴포넌트와 유닛의 불변 클래스 정보를 캐시하고 중복 조회를 줄였습니다. 소비된 사망 이벤트 데이터와 종료된 보완 오디오 컴포넌트를 정리합니다.
- 사망 연출 대기 시간이 끝난 뒤에도 남던 부착 효과·조명·반복 오디오를 정리합니다. 정상 사망 연출과 살아 있는 승객·독립 발사체는 유지합니다.

수정은 리플레이 재생에 적용합니다. 원본 .replay / .movement 파일과 녹화 형식은 변경하지 않았습니다. 업데이트 후 게임과 런처를 완전히 종료하고 다시 실행하세요.

실제 수용·하차, HUD 반복 전환, 일시정지 및 배속 검증과 수정 전후 성능 측정은 docs/PERFORMANCE-VALIDATION.md에 기록했습니다. 후반 대규모 전투의 부하까지 모두 제거했다고 주장하지 않습니다.
