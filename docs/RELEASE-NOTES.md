v0.3.19

- 리플레이의 실제 발사체 명중 이벤트와 게임에 로드된 사운드 자산을 연결해 타격음·해당 폭발음을 보완했습니다. 위치 기반 오디오로 재생하며 자산의 거리 감쇠를 유지합니다.
- 관측된 동일 사운드의 중복 억제, 늦은 이벤트 폐기, 활성 컴포넌트 제한, 일시정지·종료·파일 끝 정리를 추가했습니다. 진단 폴더의 audio-state.txt에서 누락 원인을 구분할 수 있습니다.
- 벙커·수송체에 들어간 병사를 위치 보정/미니맵 표시에서 제외하고 메시를 숨겨 건물 밖에서 공격하는 것처럼 보이는 현상을 보완했습니다.
- 복원된 중립 건물 모델의 색상이 실제 점령 소유자의 색상을 따르도록 수정했습니다.

수정은 재생 세션에만 적용합니다. 소리를 내기 위한 공격·피해·명중 함수 호출은 없으며, 원본 리플레이 파일은 수정하지 않습니다. 기존 .replay / .movement 쌍을 그대로 사용하세요. 업데이트 후 런처와 게임을 완전히 종료하고 다시 재생하세요.

기존 파일에서 명중 이벤트/사운드 정보가 없는 소리까지 복구하는 것은 아닙니다. 모든 무기의 발사·비행·사망음을 실제 경기와 청취 비교했다고 주장하지 않습니다. 소리 종류별 근거와 검증 한계는 docs/AUDIO-VALIDATION.md 및 docs/NATIVE-VALIDATION.md에 기록했습니다.
