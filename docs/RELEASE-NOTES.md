v0.3.27

- 런처 창이 열린 뒤 백그라운드에서 최신 정식 버전을 확인합니다. 새 버전이 있으면 현재/최신 버전을 표시하고 업데이트 여부를 묻습니다.
- ‘예’를 선택하면 기존 다운로드·SHA256 검증·백업/복구 절차로 설치하고 재실행합니다. ‘아니요’를 선택하면 다운로드 없이 런처를 계속 사용할 수 있습니다.
- 최신 버전이거나 인터넷 연결에 실패하면 자동 팝업을 띄우지 않습니다. 수동 ‘런처 업데이트’ 버튼은 유지되며 중복 작업은 차단합니다. 한국어/영어 안내를 지원합니다.
- 발견 전용 작업이 다운로드하지 않는지, 동의/거절, 최신 버전/다운그레이드 방지, 오프라인, 중복 실행 방지, 기존 업데이트 검증/복구 및 WPF UI 테스트를 확인했습니다.

기존에 배포된 v0.3.26 이하에는 시작 시 확인 코드가 없으므로 ‘런처 업데이트’ 버튼 또는 새 ZIP으로 한 번 업데이트해야 합니다. v0.3.27부터 이후 버전을 실행 시 안내합니다.
