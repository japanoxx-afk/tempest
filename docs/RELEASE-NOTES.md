리플레이 조작과 새 오프라인 기록의 유닛 이동을 개선했습니다.

- 활성 재생 창에 마우스 가두기 적용. Alt+Tab으로 창 전환 가능.
- 런처 목록의 리플레이 파일 더블클릭으로 재생.
- 0.5·1·2·4배속 선택과 적용 버튼 추가. 게임에서는 F7로 순환, F8로 일시정지.
- 새 오프라인 녹화에서 생산 유닛 이동 좌표도 기록하도록 보강.
