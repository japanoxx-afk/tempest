- 새 녹화에 유닛·건물의 실제 현재/최대 체력을 저장하고 리플레이에서 체력바를 표시합니다. U키 HUD 숨김과 연동합니다. 기존 파일에 체력이 없으면 정확한 수치는 복구할 수 없으므로 새 경기부터 녹화해 주세요.
- 같은 스냅샷의 객체 조사, 정지 대상 위치·회전 적용과 애니메이션 기본 정보 조회를 줄였습니다. 이동 보간이나 정상 전투 효과를 임의로 생략하지 않습니다.
- 체력 기록은 읽기 전용이며 표시·이동 최적화는 재생에만 적용됩니다. 실제 경기의 속도·공격·피해·이동은 변경하지 않습니다.

같은 기존 파일의 3840×2160 측정에서 중반 4배속 평균 71→85FPS, 후반 4배속 41→49FPS, 후반 1배속 41→약 59FPS로 개선됐습니다. 최종 1배속에서 카메라가 달랐던 5개 표본은 제외했으며 제외 전 평균은 57.47FPS입니다. 단일 PC의 병행 부하가 있는 표본으로, 모든 구간 60FPS 목표는 아직 미달입니다. 새 체력바가 많은 대규모 경기의 성능과 인터넷 상대의 모든 체력 전달은 별도 검증이 필요합니다.
