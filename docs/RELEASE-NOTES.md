v0.3.21

- 리플레이 기록 끝에 도달하면 종료 안내를 3초간 표시한 후 재생 전용 게임 프로세스를 자동 종료합니다.
- 엔진 exit 명령이 처리되지 않아도 기존 세션·실행 경로·시작 시각으로 제한된 감시기가 해당 재생 프로세스를 정리합니다.
- 새 경기는 런처의 게임 실행으로 시작하세요. 재생 프로세스에서 녹화되지 않는 새 경기를 시작하는 혼란을 방지합니다.
- 실제 경기 및 자동 녹화 분기는 변경하지 않았습니다.

검증: Python 139개 회귀 테스트와 PowerShell 종료 감시 테스트 통과. EOF 전에는 종료하지 않고, EOF 3초 콜백에서 종료 신호를 한 번만 기록하는 조건을 검사했습니다. 이번 변경의 실제 게임 EOF 자동 종료는 별도 실기 검증하지 않았습니다.
