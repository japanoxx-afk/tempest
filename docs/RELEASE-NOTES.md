온라인 클라이언트에서 수신한 유닛 이동을 별도 `.movement` 파일에 저장하고, 네이티브 `.replay`와 함께 관전자 재생에 적용합니다.

- 좌표와 회전을 기록하고 재생 시간에 맞춰 보간합니다. 온라인 경기 중에는 이동 명령이나 복제 플래그를 변경하지 않습니다.
- 클라이언트 리플레이에서 생존 상태가 기본값으로 복원되어 유닛·건물이 숨겨지는 경우, 녹화 당시의 존재 정보를 사용해 표시합니다.
- 런처에 이동 기록 상태를 표시하고, 리플레이 가져오기에서 같은 이름의 이동 파일도 함께 가져옵니다.
- 기존 마우스 가두기, 목록 더블클릭 재생, 배속 기능을 유지합니다.

게임을 종료하고 **런처 업데이트** 후 **경기 자동 기록 시도**를 체크한 상태에서 새 경기를 녹화하세요. `.replay`와 같은 이름의 `.movement` 파일을 같은 폴더에 보관해야 합니다. 이전 녹화에 누락된 좌표는 복구할 수 없습니다.

별도 전용 서버에 접속한 LAN 클라이언트와 AI 경기에서 파일 생성과 차량 이동 재생을 확인했습니다. 실제 인터넷 상대와의 경기는 사용자 확인이 남아 있습니다. 클라이언트가 수신하지 못한 적 유닛 정보는 기록할 수 없으며, 네이티브 리플레이에서 누락된 액터는 재생성하지 못하며, 일부 건물 표시와 체력·선택·미니맵 표식·전투 상태 복원은 아직 불완전합니다.
