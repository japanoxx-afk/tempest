v0.3.16

- 병영 출구에서 남아 있는 잘못된 수용 상태가 기록된 유닛 이동을 막지 않도록 수정했습니다. 반복 생산 시 생성 시점을 비교하고, 사라진 유닛의 기록을 새 유닛에 재연결하지 않습니다.
- 중립 오브젝트를 처음 표시할 때 파괴 외형을 강제로 설정하던 호출을 제거했습니다.
- 새 녹화의 .movement v4에 플레이어별 독트린 연구 완료 목록을 시점별로 저장합니다. 재생 중 연구 상태와 관전자 카운터를 갱신하며 실제 연구 명령이나 효과를 적용하지 않습니다.
- 재생 중 목표 지점을 지나치거나 오래 남은 투사체의 표시와 이동을 종료합니다. 재사용되는 투사체는 다음 발사 때 다시 처리합니다.

기존 v1/v2/v3 파일도 읽을 수 있습니다. 기존 파일에 기록되지 않은 독트린 연구 목록은 복원하지 않습니다. 새 버전으로 녹화한 경기부터 독트린 기록 보완이 적용됩니다. .replay와 같은 이름의 .movement를 함께 보관하세요.
