v0.3.25

- Windows PowerShell 5.1에서 한글 업데이트 진행 메시지를 잘못 읽어 JSON 오류가 발생하던 문제를 수정했습니다.
- 진행 파일을 UTF-8 BOM으로 저장해 기존 런처와 호환하고, 새 런처는 BOM 없는 UTF-8 진행 파일도 명시적으로 읽습니다.
- 한글 검증 메시지와 구버전/신버전 읽기 호환성, 체크섬 검증, 설치 실패 복구, 업데이트 버튼과 UI 테스트를 확인했습니다.

업데이트 오류가 난 구버전은 새 ZIP을 내려받아 압축을 푼 뒤 Start.cmd로 실행할 수 있습니다. 리플레이 파일은 게임 저장 폴더에 그대로 유지됩니다.
