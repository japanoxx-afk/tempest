# tempest

Tempest Rising용 Windows 리플레이 런처입니다. `Start.cmd`를 실행하세요. Windows PowerShell 5.1과 Steam이 필요합니다.

## 사용 방법

1. 게임을 종료하고 이 폴더의 최신 `Start.cmd`를 실행합니다.
2. 처음에는 `실험 모드 설치`를 누릅니다. 이미 설치했다면 다음 실행 때 브리지 코드가 자동 갱신됩니다.
3. `게임 실행 시 경기 자동 기록`을 체크하고 `Steam 게임 실행`을 누릅니다.
4. 오프라인 스커미시를 시작하면 경기 시작 후 자동으로 기록합니다. 메인 메뉴로 돌아가거나 게임을 정상 종료해 파일을 마무리합니다.
5. 게임 종료 후 런처에서 `새로고침 / 경로 저장`을 누릅니다. `.replay` 파일을 선택하고 실험적 관전자 재생을 허용한 뒤 재생 버튼을 누릅니다.

기본 저장 폴더는 `%LOCALAPPDATA%\Tempest\Saved\Demos`입니다. 과거에 녹화하지 않은 경기를 복원하지는 않습니다. `호환성 진단 실행`은 진단만 하며 녹화하지 않습니다. 일반 Steam 실행에서는 새 런처 요청이 없으면 브리지가 동작하지 않습니다. 로더까지 비활성화하려면 게임 종료 후 `실험 모드 제거`를 사용하세요. 설치 파일은 백업 폴더로 이동됩니다.

재생 화면에서 `F6`은 다음 플레이어 본진으로 이동하고, `I/J/K/L`은 화면을 단계적으로 이동합니다. `F8`은 재생 일시정지/재개입니다. 단축키는 실제 리플레이 재생 중에만 동작합니다. 창을 활성화한 상태에서 사용하세요.

## 검증 범위

2026-10-16, 설치된 Steam 빌드 25752338 / Unreal 5.4.3의 오프라인 스커미시에서 실제 `.replay` 생성과 별도 게임 실행에서의 관전자 재생을 확인했습니다. 검증 파일은 282,176바이트입니다. 원래 게임의 관전자 HUD, 양쪽 플레이어 통계, 본진 및 발전소 건설 장면을 확인했습니다. 상세 원인과 증거는 [네이티브 검증 기록](docs/NATIVE-VALIDATION.md)에 있습니다.

비공식 UE4SS를 사용하는 실험 기능입니다. 온라인 경기, 모든 맵·진영, 장시간 전투와 버전 간 호환성은 검증하지 않았습니다. 관전자 레이더는 현재 게임에서 '제한된 레이더'로 표시됩니다. 시간 탐색은 검증 중 게임 종료가 발생하여 제공하지 않습니다. 완전한 공식 리플레이 기능과 동일한 지원 범위를 의미하지 않습니다.

자동 녹화 실패의 핵심 원인은 콘솔 명령을 AI 플레이어 컨트롤러에 전달한 것이었습니다. 이제 실제 LocalPlayer를 선택하고 경기 맵의 DemoNetDriver를 등록합니다. 재생에서는 게임 전용 관전자 HUD, 카메라, 안개 및 건물 최초 표시·애니메이션을 초기화합니다. 표시 보정은 `ReplaySubsystem:IsPlaying()`인 재생 세션에만 적용되며 녹화 중인 경기에는 적용하지 않습니다. 실행 파일 패치는 사용하지 않습니다.

## 기능 및 진단

- Steam 실행, 경로 저장, `.replay` 목록·가져오기·폴더 열기
- 경기 자동 기록, 선택 파일 관전자 재생
- 실험 모드 설치·백업 제거, 호환성 진단
- GitHub Releases 업데이트, SHA256 검증 및 재시작

설정과 진단은 `%LOCALAPPDATA%\TempestReplayLauncher`에 저장됩니다. 브리지의 명령 전송과 녹화 성공은 구분됩니다. `commands.log`, `events.log`, `playback.txt`와 실제 파일 크기를 확인할 수 있습니다. 제어 흐름 테스트 23개는 모의 호스트를 사용하며 실게임 검증을 대체하지 않습니다.

## 배포

`version.json`을 올리고 일치하는 버전 태그를 push하면 GitHub Actions가 ZIP과 체크섬을 Release에 게시합니다. 런처 업데이트 버튼이 최신 정식 Release를 확인합니다. 소스 checkout에서 업데이트하면 소스가 배포 파일로 덮어써질 수 있으므로 개발용 checkout과 배포 폴더를 분리하세요.

게임 바이너리, 게임 에셋, 리플레이 내용과 계정 로그는 저장소에 포함하지 않습니다. 초기 조사 자료는 [조사 기록](docs/REPLAY-INVESTIGATION.md)을 참고하세요.
